## Security Reports

For security vulnerabilities, please email: **adbd04@gmail.com** with subject line:

```
[SECURITY] Brief description of vulnerability
```

### What to Include in Security Reports

1. **Description**: Clear explanation of the vulnerability
2. **Impact**: Potential consequences if exploited
3. **Reproduction**: Steps to reproduce the issue
4. **Affected Versions**: Which versions are affected
5. **Suggested Fix**: If you have a proposed solution

### Response Time

- Initial acknowledgment: Within 48 hours
- Status update: Within 1 week
- Resolution timeline: Depends on severity (critical issues prioritized)
